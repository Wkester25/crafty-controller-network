UPnP port forwarding

Asks your router to forward each server's port to this machine. UPnP must be enabled in the router's settings.

Cloudflare

Create an API token at dash.cloudflare.com → My Profile → API Tokens with Account → Cloudflare Tunnel → Edit, Zone → DNS → Edit and Zone → Zone → Read.

Once the tunnel is up, anyone on the internet can reach the web UI login page. Consider adding a Cloudflare Access policy for the web UI hostname.

Servers

Each server can get its own subdomain. Players connect to it directly (not through the tunnel), so its port must be forwarded: by UPnP here, or manually on your router. Minecraft Java servers also get an SRV record, so players don't need to type a port. Extra ports example: 24454/udp, 8100/tcp.
